======================================================================
  Ram Prasad Agencies — Storefront Branding & Media Folder
======================================================================

Welcome to the public assets directory for TheWatchStore.in.

Here are a few quick tips on customizing your store branding:

1. STORE LOGO:
   Drop your shop's official logo file here as `logo.webp`.
   The website header and footer will automatically detect and display it.
   Supported format: WebP (optimized high performance, transparent background).

2. HERO & SLIDER IMAGES:
   Featured watch showcase banners can be placed here or uploaded directly
   through the Admin Studio at http://admin.ramprasadwatchstore.in/

3. FAVICON:
   Browser tab icon is served as `/logo.webp`.

Everything placed in this folder is served directly at the root of the
website (e.g., http://ramprasadwatchstore.in/logo.webp).
